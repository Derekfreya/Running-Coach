## 1. Canova 全谱系百分比体系（percentage-based / full-spectrum training）

以**比赛配速 = 100%** 为锚点，把训练强度映射到一个连续谱系，而不是离散的「轻松 / 阈值 / 间歇」三档：

| 强度（占比赛配速） | 类型 | 训练目的 |
|---|---|---|
| **55–65%** | 轻松跑 | 有氧基础、恢复 |
| **90%** | 比赛支持性耐力（race-supporting endurance） | 提升支撑专项的强度耐力 |
| **95%** | 比赛专项耐力（race-specific endurance） | 马拉松等专项的耐力内核 |
| **100%** | 比赛配速 | 模拟比赛节奏 |
| **105%** | 专项速度（specific speed） | 提升神经驱动与速度储备 |
| **107–110%** | 支持性速度（supporting speed） | 短促、高质量的速度刺激 |

> 核心思想：**专项性（specificity）优先**。越是接近比赛动作模式与配速，越能转化到比赛表现；
> 不同百分比对应不同的生理适应，需在周期中组合使用，而非只练某一档。

## 2. 双阈值训练（Double Threshold，Marius Bakken）

> ⚠️ 这是 **Marius Bakken** 的方法，常被误归到 Ingebrigtsen 家族名下，注意区分。

一天内安排**两次阈值/间歇课**，利用乳酸代谢的时间差：

- **上午 · 长间歇**：6–10 分钟一段，配速偏慢、乳酸累积低；
- **下午 · 短间歇**：45-15（跑 45s / 走 15s）、1 分钟、或 200m 重复，配速快、乳酸累积高；
- **间隔**：两次课之间 **4–5 小时** 最优；
- **容量**：单日 15–20 km，上限约 40 km；
- **判据**：「让你累的是量，不是强度」——若强度已让你力竭，说明量超了，应下调。

## 3. 入门期（Introductory Training）

针对**长期中断后重返跑步**的人群：

- 低跑量本身对重返的身体就是**新的应激**，不必急于加量；
- 以 **effort-based（主观努力度）** 而非严格配速来安排，避免用旧 PB 的配速要求退步后的身体；
- 优先恢复**心理能量与跑步习惯**，体能会随规律跑步自然回来。

---

## 4. 减量（Taper）

结构化减量的价值在于**卸掉累积疲劳、把状态 sharpen 出来**，而非保体能（有氧体能需数周才掉）。

- 依据：**Bosquet 等 2007 年 Meta 分析（27 项研究）**——结构化减量平均带来 **约 2–3%** 成绩提升；
- 通用参数：减量时长约 2 周为甜区；跑量降 **40–60%**；**强度保持、频率保持（≥80%）**——只砍垃圾跑量，不砍质量课；
- 短距离（如 10K）可更短（7–10 天），过长反而发沉、丢锐度；
- 保留一次「最后刺激课」（赛前 5–7 天，如 3–4 × 1K @ 比赛配速，或几组 strides）。

---

## 5. 强度分布的结构性问题

实战中常见的失衡：**真轻松跑太少、大量「中庸跑」挤在中等~强区间、真间歇太少**。

- 后果：有氧基础（靠大量真轻松跑建立）不足，又缺乏高质量间歇刺激，瓶颈明显；
- 修正：把轻松跑真正跑慢（落在可对话区间），每周补 1–2 次真间歇。

## 7. 关键术语速查

| 术语 | 含义 |
|---|---|
| LT1 / LT2 | 一级 / 二级乳酸阈（有氧阈 / 无氧阈） |
| Critical Speed/Velocity | 临界速度，介于阈值与 VO2max 之间的可持续强度 |
| Specific Endurance | 比赛专项耐力（≈95% 比赛配速区间） |
| Supportive Endurance | 比赛支持性耐力（≈90% 比赛配速区间） |
| Strides | 短促加速跑（80–100m），用于激活神经、赛前 sharpen |
| Physiological Resilience | 生理韧性，马拉松等长距离所需的抗疲劳能力 |
